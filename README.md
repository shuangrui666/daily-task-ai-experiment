# 日常数字任务耗时审计与 AI 批处理实证

> 使用同一批10个文件的批量重命名任务，对比纯人工与AI对话辅助方式的耗时和命名正确性。

## 1. 项目简介

- **A组：纯人工**——实验者按统一规则自行判断并重命名。
- **B组：AI对话辅助**——AI生成目标文件名清单，实验者手动执行重命名。
- 两组均使用同一批10个原始文件名。AI不直接操作实验者电脑。

统一格式：`日期_类别_主题.扩展名`。类别只能是：`作业、笔记、截图、资料`。

## 2. 实验结果

### 耗时

| 组别 | 第1次 | 第2次 | 第3次 | 平均耗时 |
|---|---:|---:|---:|---:|
| 纯人工 A组 | 516秒 | 422秒 | 360秒 | 432.67秒 |
| AI辅助 B组 | 289秒 | 196秒 | 122秒 | 202.33秒 |

- A组平均耗时：432.67秒（约7分13秒）
- B组平均耗时：202.33秒（约3分22秒）
- 平均耗时差：230.33秒
- B组平均耗时比A组低约 **53.26%**

计时终点为10个文件全部完成重命名；完成后逐个检查，检查时间不计入耗时。B组第3次（2026-11-08）已确认对应122秒；B组第1、2次的日期与耗时对应关系尚未由独立原始计时记录再次确认，因此不在此强行绑定日期。

### 正确性

| 组别 | 逐轮结果 | 正确数/总数 | 准确率 | 核验依据 |
|---|---|---:|---:|---|
| A组纯人工 | 3轮均为10/10 | 30/30 | 100% | 实验者此前逐项检查确认，原始逐轮证据未全部归档 |
| B组AI辅助 | 第1、2、3轮均为0/10 | 0/30 | 0% | 三轮原始ZIP逐项审计 |
| 合计 |  | 30/60 | 50% | A组为实验者确认；B组为ZIP审计 |

**B组专项复核：** B1（2026-10-24）、B2（2026-10-29）和B3（2026-11-08）的原始ZIP均已逐项核验。每轮10个文件的第二字段均不是规则允许的“作业、笔记、截图、资料”之一，因此三轮均为0/10。B1、B2、B3各自的逐项结果和证据清单分别见 `evidence/ai/B1/`、`evidence/ai/B2/`、`evidence/ai/B3/`。

此前“B组20/30正确”“总体50/60正确”等统计已撤回。A组30/30仍是实验者确认结果，不应描述为已通过原始ZIP独立复核。

## 3. 解释与局限

本实验中AI辅助方式的平均完成时间较短，但三轮AI辅助结果均未满足严格命名规则。准确结论是：**本次小样本中，AI辅助组平均耗时降低约53.26%，但三轮原始ZIP审计均为0/10正确，显示速度提升伴随严重的规则遵循问题。** 因此不能声称AI辅助在保持命名质量的同时节省时间。

每组仅3次，且同一实验者重复操作，存在熟练度效应。A组正确性依据实验者此前逐项检查确认，缺少完整逐轮原始ZIP/截图证据；B组正确性则有三轮原始ZIP逐项审计支持。B组B1、B2、B3原始屏幕录制和ZIP证据均已归档。视频提取帧是派生参考材料，不是原始静态截图。B组第1、2次的具体日期与289秒、196秒耗时的映射尚待原始计时记录确认。
