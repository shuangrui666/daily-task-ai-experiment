# 日常数字任务耗时审计与 AI 批处理实证

> 通过同一批10个文件的批量重命名任务，对比纯人工与 AI 对话辅助方式的耗时和命名正确性。

## 1. 项目简介

- **A组：纯人工**——实验者按统一规则自行判断并重命名。
- **B组：AI对话辅助**——AI生成目标文件名清单，实验者手动执行重命名。
- 两组均使用同一批10个原始文件名。AI不直接操作实验者电脑。

统一格式：`日期_类别_主题.扩展名`。类别只能是：`作业、笔记、截图、资料`。

## 2. 实验结果

### 耗时

| 组别 | 第1次 | 第2次 | 第3次 | 平均耗时 |
|---|---:|---:|---:|---:|
| 纯人工 A组 | 516秒 | 422秒 | 360秒 | 432.67秒 |
| AI辅助 B组 | 289秒 | 196秒 | 122秒 | 202.33秒 |

- A组平均耗时：432.67秒（约7分13秒）
- B组平均耗时：202.33秒（约3分22秒）
- 平均耗时差：230.33秒
- B组平均耗时比A组低约 **53.26%**

计时终点为10个文件全部完成重命名；之后逐个检查，检查时间不计入耗时。

### 正确性（按已核实的逐轮结果）

| 组别 | 逐轮结果 | 正确数/总数 | 准确率 |
|---|---|---:|---:|
| A组纯人工 | 3轮均为10/10 | 30/30 | 100% |
| B组AI辅助 | 第1、2轮各10/10；第3轮0/10 | 20/30 | 66.67% |
| 合计 |  | 50/60 | 83.33% |

**重要修订：** 2026-11-08核对确认，该次是B组第3次（122秒）。用户确认下载ZIP中的10个实际文件名与当轮AI回复列出的名称完全一致。逐项按本实验命名规则复核后，10个名称均不符合规则：类别字段使用了“英语、机器学习、课程截图、Python、高等数学、课程表、数据库、数学”等非允许类别，且多项字段顺序错误。因此B组第3次修订为0/10正确。此前“B组30/30正确、两组均100%”的汇总结论已撤回。

这次复核是对B组第3轮的具体证据核对，优先于此前笼统的“六轮均正确”概括。B组第1、2轮及A组3轮暂按实验者此前逐项检查确认记录。证据来源和限制见审查报告及 `data/ai_trial3_output_audit.csv`。

## 3. 解释与局限

本实验中AI辅助方式的平均完成时间较短，但B组正确性并未保持100%。因此不能再得出“AI在保持正确率的同时节省时间”的结论。更准确的结论是：**本次小样本中，AI辅助组平均耗时降低约53.26%，但第3轮出现10/10命名规则错误，说明AI输出必须逐项校验。**

每组仅3次，且同一实验者重复操作，存在熟练度效应。正确性结果主要来自实验者确认；目前仅B组第3轮有本次对话中可追溯的AI输出清单及ZIP一致性确认，尚无ZIP本体或逐轮截图附件供独立复核。结果仅适用于本次样本和实验条件。
