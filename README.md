# 日常数字任务耗时审计与 AI 批处理实证

> 使用同一批10个文件的批量重命名任务，对比纯人工与AI对话辅助方式的耗时和命名正确性。

## 1. 项目简介

- **A组：纯人工**——实验者按统一规则自行判断并重命名。
- **B组：AI对话辅助**——AI生成目标文件名清单，实验者手动执行重命名。
- 两组均使用同一批10个原始文件名。AI不直接操作实验者电脑。

统一格式：`日期_类别_主题.扩展名`。类别只能是：`作业、笔记、截图、资料`。

## 2. 实验结果

### 耗时

| 组别 | 第1次 | 第2次 | 第3次 | 平均耗时 |
|---|---:|---:|---:|---:|
| 纯人工 A组 | 516秒 | 422秒 | 360秒 | 432.67秒 |
| AI辅助 B组 | 289秒 | 196秒 | 122秒 | 202.33秒 |

- A组平均耗时：432.67秒（约7分13秒）
- B组平均耗时：202.33秒（约3分22秒）
- 平均耗时差：230.33秒
- B组平均耗时比A组低约 **53.26%**

计时终点为10个文件全部完成重命名；之后逐个检查，检查时间不计入耗时。

### 正确性

| 组别 | 逐轮结果 | 正确数/总数 | 准确率 |
|---|---|---:|---:|
| A组纯人工 | 3轮均为10/10 | 30/30 | 100% |
| B组AI辅助 | 第1、2轮各10/10；第3轮0/10 | 20/30 | 66.67% |
| 合计 |  | 50/60 | 83.33% |

**B组第3轮专项修订：** 2026-11-08这轮为B组第3次，耗时122秒。用户确认ZIP内10个文件名与当轮AI回复完全一致；逐项对照命名规则后，10个名称均不合格。因此该轮记为0/10。逐项结果见 `data/ai_trial3_output_audit.csv`，原始证据包见 `evidence/ai/B3_original_evidence_bundle.zip`。

B组第1、2轮及A组3轮暂按实验者此前逐项检查确认记录。B组第3轮具体证据优先于此前笼统的“六轮均正确”概括；旧的B组30/30和两组均100%结论已撤回。

## 3. 解释与局限

本实验中AI辅助方式的平均完成时间较短，但B组正确性并未保持100%。准确结论是：**本次小样本中，AI辅助组平均耗时降低约53.26%，但B组第3轮出现10/10命名规则错误，说明AI输出必须逐项校验。**

每组仅3次，且同一实验者重复操作，存在熟练度效应。A组及B组前两轮的正确性依据实验者此前确认，尚缺完整逐轮原始检查附件。B组第3轮已归档原始屏幕录制视频和ZIP证据包；视频提取帧为辅助材料，不是原始截图。结果仅适用于本次样本和实验条件。
