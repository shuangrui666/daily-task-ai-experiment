# 日常数字任务耗时审计与 AI 批处理实证

> 使用同一批10个文件的批量重命名任务，对比纯人工与AI对话辅助方式的耗时和命名正确性。

## 1. 项目简介

- **A组：纯人工**——实验者按统一规则自行判断并重命名。
- **B组：AI对话辅助**——AI生成目标文件名清单，实验者手动执行重命名。
- 两组均使用同一批10个原始文件名。AI不直接操作实验者电脑。

统一格式：`日期_类别_主题.扩展名`。类别只能是：`作业、笔记、截图、资料`。

## 3. 解释与局限

本实验中AI辅助方式的平均完成时间较短，但三轮AI辅助结果均未满足严格命名规则。A组事后文件名审核正确率为93.33%，B组原始ZIP审计正确率为0%。因此不能声称AI辅助在保持命名质量的同时节省时间。

准确结论是：**本次小样本中，AI辅助组平均耗时降低约53.96%，但命名正确率为0%；人工组命名正确率为93.33%，平均耗时较长。** 这说明在本次规则和样本下，未经规则校验的AI命名清单存在严重风险。

每组仅3次，且同一实验者重复操作，存在熟练度效应。A组审核依据是GitHub中最终结果文件名及预定映射，未下载并逐一验证文件内容；A组过程截图、录屏和独立计时原始材料未全部归档。B组正确性有三轮原始ZIP逐项审计支持。B组视频提取帧是派生参考材料，不是原始静态截图。B组第1、2次的日期与耗时映射已由用户提供的计时照片确认：B1为2026-10-24、00:04:49.64；B2为2026-10-29、00:03:16.42。
