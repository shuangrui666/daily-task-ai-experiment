# AI辅助组实验使用的 Prompt

以下为实验使用的标准化要求。每轮测试应在新对话中提交完整要求，并使用同一批原始文件名。

```text
我正在进行一项“日常数字任务耗时审计与 AI 批处理实证”实验，本次任务是对10个文件进行批量重命名。

请根据以下要求，帮我统一文件名。

一、命名规则
1. 统一格式为：日期_类别_主题.扩展名
2. 日期统一为 YYYY-MM-DD 格式。
3. 类别只能使用：作业、笔记、截图、资料。
4. 主题应简洁、清晰，能够体现文件内容。
5. 必须保留每个文件原来的扩展名。
6. 不得遗漏任何文件，不得擅自更改文件的实际内容。
7. 如果原始文件名中的日期或类别存在歧义，请明确指出，不要随意猜测。

二、原始文件名
1. 数学作业10月20日.docx
2. Python笔记_2026.10.21.md
3. IMG_20261022_课程截图.png
4. 英语资料-10.18.pdf
5. 高数作业（10月19日）.pdf
6. 2026_10_23_机器学习笔记.txt
7. 数据库作业_2026年10月24日.docx
8. 10-17英语笔记.docx
9. 课程表截图2026-10-16.jpg
10. Python学习资料（2026.10.15）.pdf

三、输出要求
请使用表格列出序号、原始文件名、建议的新文件名、命名依据或需要注意的问题。

最后，请检查是否有10个文件、日期格式是否统一、类别是否符合要求、扩展名是否保留，以及新文件名之间是否存在重复。

请注意：你只需要生成重命名方案，不需要编写代码，也不要声称已经修改了我电脑上的文件。
```

## 实验记录注意

- 保存每轮实际提交的 Prompt 和 AI 输出；若三轮使用的 Prompt 有改动，应保留各轮版本或说明差异。
- 记录 AI 输出后，由实验者手动执行重命名。
- AI 生成方案的时间不是全部任务耗时，实验计时应按统一实验方案执行。
- 不要把 AI 输出的建议名称直接当作已验证的最终文件名。
