# B组原始Prompt归档核查

## 核查结论

截至本次仓库核查，B1、B2、B3三轮实际提交给AI的完整Prompt原文均未找到可核验的逐字记录。现有材料不能支持重建或声称恢复了历史Prompt。

| 轮次 | 已有材料 | 缺失内容 | 证据处理 |
|---|---|---|---|
| B1 | 屏幕录制视频、对话过程文字摘录、最终ZIP与审计CSV | 完整逐字Prompt | 视频可辅助说明对话发生过，但现存摘录未逐字保存用户输入；不反向补写 |
| B2 | 屏幕录制视频、AI输出名称摘录、最终ZIP与审计CSV | 完整逐字Prompt | 输出摘录不是Prompt记录；不根据输出推测输入 |
| B3 | 用户粘贴的历史AI回复摘录、最终ZIP与审计CSV | 完整逐字Prompt、原生聊天导出 | 明确标注为用户粘贴内容整理，不冒充原生聊天记录 |

## 不能采用的补救方式

- 不得把仓库中的标准化Prompt模板冒充B1、B2、B3实际使用的原文。
- 不得把后续改进Prompt冒充历史Prompt。
- 不得根据AI输出结果反向推断并编造用户当时的输入措辞。
- 不得删除或覆盖历史输出、ZIP、计时数据和审计记录。

## 如能找回原始会话

从当时使用的AI平台历史会话中逐轮复制原始用户输入，或保存带有会话上下文的原始截图/导出文件。每份材料应注明轮次、来源平台、会话日期及是否完整；原文件保持不变，并计算SHA-256。补充材料应标记为后续找回归档，不得改变原始实验数据。

## 如无法找回

保留本核查结论，并在报告中说明：由于三轮原始Prompt未完整归档，无法逐字审查当时的指令约束，因此Prompt不够准确只能作为可能影响因素，不能认定为已证实的直接原因。这是证据留存局限，不应以虚构文本掩盖。
