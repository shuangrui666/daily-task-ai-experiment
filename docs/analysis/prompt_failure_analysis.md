# Prompt执行失败原因分析（基于现有证据）

## 1. 分析目的与证据边界

本分析用于解释B1、B2、B3三轮AI批量重命名结果为何未通过命名规则检查，并区分Prompt约束、AI执行和证据留存问题。

**重要限制：** 仓库当前的 `docs/ai_prompt.md` 原有Prompt文本明确要求AI只生成重命名方案、不实际修改文件；但实验者已确认历史B组的真实操作是上传10个文件、提交Prompt、由AI直接重命名并提供可下载结果。因此，仓库现存文本不能被当作B1、B2、B3逐轮实际提交的Prompt原文。三轮原生Prompt未完整归档，无法据此逐字判定当时每条关键词是否充分。

## 2. 从真实输出中观察到的稳定错误

| 轮次 | 错误文件数 | 主要可见问题 | 证据 |
|---|---:|---|---|
| B1 | 10/10 | 类别字段常放入学科或主题词，如英语、机器学习、课程、Python；类别与主题顺序颠倒 | `evidence/ai/B1/B1_output_audit.csv` |
| B2 | 10/10 | 第二字段全部不是允许类别，出现英语、机器学习、课程、Python、数学等 | `evidence/ai/B2/B2_output_audit.csv` |
| B3 | 10/10 | 第二字段全部不是允许类别；部分输出还出现字段顺序颠倒、主题冗余或加入额外描述 | `data/ai_trial3_output_audit.csv` |

三轮共30个输出文件，均未通过既定命名规则；其中最稳定、最明确的错误模式是类别字段不属于“作业、笔记、截图、资料”四项白名单。

## 3. Prompt可能存在的约束缺口

以下属于基于错误模式提出的可能解释，不是已经证明的历史因果结论：

1. **类别字段约束可能不够强。** AI多次把“英语”“数学”“Python”“机器学习”等主题词放在类别位置，说明执行结果没有遵守类别白名单及字段角色。
2. **字段位置约束可能不够明确或未被遵守。** 多轮输出将“笔记”“作业”“资料”“截图”放在第三字段，而不是第二字段。
3. **交付前检查可能没有有效拦截错误。** 三轮结果均有类别字段错误，说明最终交付前的自检没有把这些错误修正到符合规范的状态；但不能确定是Prompt没有要求自检，还是AI要求了却未执行。
4. **主题提取可能缺少边界。** B3出现“学习笔记”“PetHome页面”等更长主题，可能与主题简洁性和不添加无依据描述的约束不足有关。

## 4. 目前不能下的结论

- 不能断言30个错误全部由Prompt关键词不准确造成。
- 不能断言AI模型本身无法完成文件重命名。
- 不能把仓库现存的标准模板当作三轮实际Prompt原文。
- 不能仅凭输出错误判断当时Prompt是否明确写了类别白名单；需要逐轮原始Prompt或聊天记录才能确认。

## 5. 建议的Prompt改进方向

后续Prompt应明确写出：

1. 只允许四个类别：作业、笔记、截图、资料；不允许将学科名称当作类别。
2. 字段位置固定为：第一字段日期、第二字段类别、第三字段主题。
3. 字段之间只能使用ASCII下划线；日期内部保留连字符。
4. 日期必须是有效日期，扩展名必须与原文件一致。
5. 主题只能提取原文件名或文件内容中有依据的信息，不添加推测性描述。
6. AI必须直接处理上传文件并交付重命名后的文件包；不能只返回建议清单。
7. 交付前逐个核对数量、类别白名单、字段顺序、扩展名、重名和一一对应关系；发现错误先修正再交付。

改进Prompt已作为建议版本放在 `docs/ai_prompt.md`，不覆盖历史Prompt，不作为B1–B3已执行的证据。

## 6. 后续验证设计

使用相同10个原始文件和同一套标准映射，另行开展优化Prompt测试。至少记录：实际Prompt原文、AI处理开始与交付下载完成时间、输出压缩包、逐项审计CSV、错误类型和SHA-256。新实验单独编号，不修改B1–B3历史数据。

## 7. 结论

现有证据能够确认B1、B2、B3三轮AI输出均未满足命名规范，最突出的共同问题是类别字段不在白名单内。Prompt约束不够明确是合理的待验证解释之一，但由于逐轮原始Prompt未完整归档，当前不能将其认定为唯一或已证实的直接原因。
