## 2. 已发现并修正的问题

### 2.1 正确性检查状态不一致

此前CSV和报告曾将检查标为未进行或待核验，与实验者确认的实际操作不一致。现已统一记录：六轮测试均在重命名计时结束后逐个检查，且每轮10个文件全部正确，无需修改。

### 2.2 CSV缺少结构化正确性字段

现已在 `data/experiment_data.csv` 增加正确数、错误数、遗漏数、准确率及证据来源字段。每轮按实验者确认记录为10/10正确。

### 2.3 计时是否包含检查表述含糊

现已在README、实验设计和分析报告中统一说明：计时终点是10个文件全部完成重命名；随后进行逐个检查，检查时间不计入重命名耗时。

### 2.4 文档对正确性证据来源说明不足

现已统一注明：正确性结果来自实验者确认，当前没有每轮独立检查表或截图作为第三方审计证据。报告不将其伪装为独立验证。

### 2.5 日期信息的来源说明

部分原始文件名只包含月日，没有明确年份。映射表保留实验者确认的2026年目标日期，并在相应行注明年份是按实验者检查结果确认，而非由文件名本身完整提供。
