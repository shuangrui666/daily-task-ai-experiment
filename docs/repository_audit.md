## 2. 已发现并修正的问题

### 2.1 B组第3轮正确性被错误记为100%

此前README、CSV和报告均把B组3轮记为30/30正确。此次具体核对发现B组第3轮AI回复及ZIP内实际名称10/10不符合命名规则。现已修订：

- B组第3轮：0/10，错误10个，准确率0%。
- B组整体：20/30，准确率66.67%。
- A组：按此前实验者确认，30/30，准确率100%。
- 六轮合计：50/60，准确率83.33%。

### 2.2 结果结论同步修正

耗时数据不变：A组平均432.67秒，B组平均202.33秒，B组平均耗时降低约53.26%。但不能再声称AI辅助“保持100%正确率”；报告现已明确说明速度提升伴随输出质量风险。

### 2.3 文件映射表的含义澄清

`data/filename_mapping.csv` 是符合规则的标准目标名称参考，不是六轮实际输出的逐轮证据。已将状态标注为 `reference_standard`，避免将参考映射误读为每轮实际文件名均已核验。

### 2.4 B组第3轮逐项审计留档

新增 `data/ai_trial3_output_audit.csv`，记录AI输出的10个名称、类别字段、规则判定和原因。该表根据用户粘贴的AI回复及用户确认ZIP与回复一致编制。
