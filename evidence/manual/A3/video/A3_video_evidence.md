## 为什么使用百度网盘
实验过程视频属于媒体文件，体积可能较大。GitHub 更适合保存项目代码、结构化实验数据、审核记录和文档；将较大视频直接放入普通 Git 仓库会增加仓库体积，也受到网页上传和普通 Git 推送的文件大小限制。

因此，本项目采用分工存储方式：由百度网盘保存 A3 视频文件，GitHub 保存视频索引、分享入口、实验审核记录和证据说明。这样可以避免为了满足 GitHub 上传限制而过度压缩视频、影响画面辨识度，同时让项目证据目录保留可追溯的查阅入口。

## 证据用途
实验者已确认，该视频覆盖A3从开始操作到10个文件全部完成的过程，可作为整轮实验过程的补充佐证。它不是电脑屏幕录制。

## 证据局限
1. 本视频不是电脑屏幕录制，不能单独核验每个文件最终显示的具体文件名及其规则符合性。
2. 10个最终文件名的审核结论以同目录的 `A3_output_audit.csv` 为准（9/10符合规则，90%）。
3. 计时照片 `../timing/A3.jpg` 支持计时器显示00:06:00.28；视频和照片均不能单独证明计时器精确的开始、停止动作。
4. 本说明记录用户提供的网盘分享信息；未对网盘文件进行独立下载、播放或完整性校验。
5. 本说明不推断视频的具体时长、文件大小、压缩参数或原始文件保留情况；这些信息如经核实，可另行补充。
