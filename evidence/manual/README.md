## 证据解释

1. 过程视频用于佐证实验实际开展及实验者完成整轮操作；视频不是屏幕录制，不能单独核验每个文件名的具体变化。
2. A2、A3计时照片支持计时器最终显示值，但单张照片不能独立证明精确的开始和停止动作。
3. A1没有独立计时照片，保留516秒原始记录，并明确披露这一证据差异。
4. 最终文件名正确性以各轮审计CSV为准：A1 9/10、A2 10/10、A3 9/10。
5. 不修改原始实验结果，不伪造缺失的计时照片或过程证据。
