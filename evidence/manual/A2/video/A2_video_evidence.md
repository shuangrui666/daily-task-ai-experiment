## 为什么使用百度网盘
实验过程视频属于体积较大的媒体文件。GitHub 更适合保存项目代码、结构化实验数据、审核记录和文档；将较大视频直接放入普通 Git 仓库会增加仓库体积，也受到网页上传和普通 Git 推送的文件大小限制。

因此，本项目采用分工存储方式：由百度网盘保存 A2 视频文件，GitHub 保存视频索引、分享入口、实验审核记录和证据说明。这样可以避免为了满足 GitHub 上传限制而过度压缩视频、影响画面辨识度，同时让项目证据目录保留可追溯的查阅入口。

## 证据用途
该视频作为 A2 实验过程的辅助材料，用于补充说明实验过程有相应视频记录。它属于实验过程视频，不是电脑屏幕录制。

## 证据局限
1. 本视频不是屏幕录制，不能单独还原每个文件在电脑上的完整重命名操作轨迹。
2. 不能仅凭该视频证明10个最终文件名逐项正确；命名审核结论以同目录的 `A2_output_audit.csv` 为准（10/10符合规则）。
3. 不能仅凭该视频证明A2实验耗时的准确性或独立计时过程。
4. 本说明记录用户提供的网盘分享信息；未对网盘文件进行独立下载、播放或完整性校验。
5. 当前不据此推断视频的具体时长、文件大小、压缩参数或原始文件保留情况；这些信息如经核实，可另行补充。
