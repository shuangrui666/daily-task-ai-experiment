# A2 Manual Group Evidence

本目录用于保存A2人工组第二轮实验的最终结果及审核证据。

## 实验基本信息

- 实验组别：A2（人工组第二轮）
- 实验方式：人工完成文件重命名
- 目标文件数量：10个
- 命名规则：`YYYY-MM-DD_类别_主题.扩展名`

## 实验结果文件

请在本目录上传A2第二轮实际完成重命名后的10个文件。

注意：
- 保留实验当时的实际文件名。
- 不要为了通过审核而提前修改错误文件名。
- 不要用其他轮次的文件代替A2文件。

## 审核记录

待上传10个文件后进行逐项审核，计划生成：

- `A2_output_audit.csv`：10个文件的逐项命名审核结果。
- `A2_ARCHIVE_MANIFEST.md`：审核范围、方法、结果及证据限制。

## 过程证据

如有实验当时产生的材料，请一并归档：

- 实验过程截图
- 屏幕录制视频
- 原始计时记录

没有保存的材料标记为缺失，不补造历史证据。
